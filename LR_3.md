# Социальная сеть

## Тема проекта

Проект реализует backend-сервис социальной сети с возможностью взаимодействия пользователей через публикации, комментарии, лайки и подписки.

## Основные сущности

В сервисе используются следующие основные сущности:

- User (Пользователь) — зарегистрированный участник социальной сети
- Post (Пост) — публикация пользователя
- Comment (Комментарий) — комментарий к посту
- Like (Лайк) — отметка «нравится» для поста
- Follow (Подписка) — связь подписки одного пользователя на другого

## Поддерживаемые операции

Сервис предоставляет REST API и поддерживает следующие операции:

- управление пользователями (создание, просмотр, обновление, удаление);
- создание и управление постами;
- получение ленты постов от подписанных пользователей;
- добавление и редактирование комментариев;
- постановка и удаление лайков;
- подписка и отписка от пользователей.

Проект предназначен для демонстрации базовой логики социальной сети и работы с REST API.
