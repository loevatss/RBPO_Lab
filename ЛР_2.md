Лабораторная работа 2 — Социальная сеть (CRUD)

Вариант: «Социальная сеть — User, Post, Comment, Like, Follow».
Цель: для каждой сущности реализовать контроллеры с методами Создания, Получения, Изменения и Удаления; показать базовые операции лайков и подписок; собрать и запустить сервис.

1. Модель данных

- User: `id`, `username`, `name`
- Post: `id`, `userId`, `text`, `createdAt`
- Comment: `id`, `postId`, `userId`, `text`, `createdAt`
- Like: связь (userId, postId), один лайк на пару
- Follow: связь (followerId → followeeId)

2. Конечные точки (эндпоинты)

- Users (`/api/users`):
  - POST `/` — создать пользователя
  - GET `/` — список пользователей
  - GET `/{id}` — получить
  - PUT `/{id}` — обновить
  - DELETE `/{id}` — удалить
- Posts (`/api/posts`):
  - POST `/` — создать пост
  - GET `/` — список постов
  - GET `/{id}` — получить
  - GET `/user/{userId}` — посты пользователя
  - PUT `/{id}` — обновить
  - DELETE `/{id}` — удалить
  - GET `/feed/{userId}` — лента из постов подписок
- Comments (`/api/comments`):
  - POST `/` — создать комментарий
  - GET `/{id}` — получить комментарий
  - GET `/post/{postId}` — комментарии к посту
  - PUT `/{id}` — обновить
  - DELETE `/{id}` — удалить
- Likes (`/api/likes`):
  - POST `/` — поставить лайк (body: userId, postId)
  - DELETE `/` — снять лайк (body: userId, postId)
  - GET `/post/{postId}` — список userId, кто лайкнул, и/или счётчик
- Follows (`/api/follows`):
  - POST `/` — подписаться (body: followerId, followeeId)
  - DELETE `/` — отписаться (body: followerId, followeeId)
  - GET `/{userId}` — список followeeId (на кого подписан)

3. Сборка и запуск (из корня репозитория)

1) Соберите: `mvn clean package`
2) Запустите:
   - Вариант 1: `mvn spring-boot:run`
   - Вариант 2: `java -jar target/spring-social-0.0.1-SNAPSHOT.jar`

4. Быстрые примеры запросов (PowerShell и Bash)

- Создать пользователя:
  - `curl.exe -X POST http://localhost:8080/api/users -H 'Content-Type: application/json' -d '{ "username": "john", "name": "John Doe" }'`
- Создать второго пользователя:
  - `curl.exe -X POST http://localhost:8080/api/users -H 'Content-Type: application/json' -d '{ "username": "jane", "name": "Jane Roe" }'`
- Создать пост (userId=1):
  - `curl.exe -X POST http://localhost:8080/api/posts -H 'Content-Type: application/json' -d '{ "userId": 1, "text": "Hello!" }'`
- Создать пост (userId=2):
  - `curl.exe -X POST http://localhost:8080/api/posts -H 'Content-Type: application/json' -d '{ "userId": 2, "text": "Hi from Jane" }'`
- Подписаться (1 → 2):

  - `curl.exe -X POST http://localhost:8080/api/follows -H 'Content-Type: application/json' -d '{ "followerId": 1, "followeeId": 2 }'`

- Лента (для userId=1):

  - `curl.exe http://localhost:8080/api/posts/feed/1`
  - Поставить лайк (userId=1, postId=1):
    - `curl.exe -X POST http://localhost:8080/api/likes -H 'Content-Type: application/json' -d '{ "userId": 1, "postId": 1 }'`

Примечания

- Реализация хранит данные в памяти процесса и сбрасывается при перезапуске. Для реального проекта вы бы использовали базу данных (например, PostgreSQL) и Spring Data JPA.
- Валидируются простые поля; расширенную валидацию и безопасность (аутентификацию) можно добавить позже.
- Если видите ошибки вида `JSON parse error: Unexpected character ('\' ...)` — это из‑за неправильного экранирования в PowerShell. Используйте варианты команд выше (с одинарными кавычками или Invoke-RestMethod).
