Лабораторная работа 1 — Введение в Spring Boot (3.5.5+)

1. Подготовка окружения

- Установите IntelliJ IDEA (рекомендуется Ultimate, но подойдёт и Community).
- JDK 21+: проверьте `java --version` (в PowerShell или CMD).
- Maven: проверьте `mvn -v`. Если команда не находится — добавьте путь `...\maven\bin` в PATH.

2. Структура проекта

- Папка: `spring-social`
- Основные файлы:
  - `spring-social/pom.xml` — конфигурация Maven, Spring Boot 3.5.5+, Java 21.
  - `spring-social/src/main/java/com/example/social/SocialApplication.java` — точка входа.
  - `spring-social/src/main/java/com/example/social/HelloController.java` — простой контроллер.

3. Пример простого контроллера

- GET `/hello` — вернёт строку "Hello from Spring Boot!".
- GET `/sum?a=2&b=3` — вернёт сумму `5`.

4. Сборка и запуск

1) Соберите JAR:
   - `mvn clean package`
1) Варианты запуска:
   - Быстрый запуск: `mvn spring-boot:run`
   - Или запуск с JAR: `java -jar target/spring-social-0.0.1-SNAPSHOT.jar`

5. Проверка в браузере/через curl

- `http://localhost:8080/hello`
- `http://localhost:8080/sum?a=10&b=32`
