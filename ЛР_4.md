```bash

# 2. Использовать в запросе
curl -u 'LOGIN:PASSWORD' -b cookies.txt -c cookies.txt \
  -H "X-XSRF-TOKEN: $TOKEN" \
  -H "Content-Type: application/json" \
  -X METHOD \
  -d 'JSON_BODY' \
  http://localhost:8080/api/endpoint
```

## 3) Регистрация

Регистрация **публичная** (не требует BasicAuth), но CSRF обязателен.

**Требования к паролю:**

- Минимум 8 символов
- Минимум 1 спецсимвол (!@#$%^&\* и т.д.)

```bash
# Получить свежий CSRF
curl -c cookies.txt http://localhost:8080/api/auth/csrf > csrf.json
TOKEN=$(python3 -c 'import sys,json; print(json.load(open("csrf.json"))["token"])')

# Зарегистрировать пользователя
curl -b cookies.txt -c cookies.txt \
  -H "X-XSRF-TOKEN: $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"login":"user1","password":"Strong!Pass1"}' \
  http://localhost:8080/api/auth/register

# Ответ: {"id":2,"login":"user1","roles":["ROLE_USER"]}
```

Дальше `user1:Strong!Pass1` используется для Basic Auth.
